About

Fraud Detection Graph AI is a lightweight analytics tool for transaction monitoring, anomaly detection, and network risk exploration.

Purpose

Provide a polished dashboard experience for visualizing suspicious transaction networks and generating operational reports.

Capabilities

  • CSV upload and live model scoring
  • Graph-based fraud visualization
  • Transaction filtering and export
  • Analytics and report generation

Built With

Flask, Pandas, Plotly, NetworkX, scikit-learn, and simple responsive UI design.
